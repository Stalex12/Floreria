## Definition of Ready (DoR)
- Historia de Usuario redactada correctamente
- Criterios de aceptación definidos
- Etiquetas de prioridad y estimación asignadas
- Diseño de interfaz definido

## Definition of Done (DoD)
- Funcionalidad implementada
- Interfaz validada manualmente
- Cambios subidos al repositorio
- Revisión final completada
